# 報告の体裁 (骨格)

```markdown
## 検証結果

- 対象: <検査対象の絶対パス>
- チェックリスト: <どの skill のどの節か>
- 実行モード: <self-check | レビュア subagent (観点: ...) | self-check (subagent 起動不可のため縮退、独立性なし)。縮退の経緯 (先行試行の有無・確認方法) など補足があればこの欄に自由記述で続ける>
- 集計: <観点名> N 項目中 ○ a、× b、対象外 c / <観点名> ... — <成功 | 失敗> (`[critical]` の判定)

### 判定

| 項目       | 判定   | 理由                |
| ---------- | ------ | ------------------- |
| <観点名> 1 | ○      |                     |
| <観点名> 2 | ×      | <該当箇所> — <根拠> |
| <観点名> 3 | 対象外 | <理由>              |

### 指摘

| 項目       | 重要度 | 箇所   | 問題   | 根拠   | 修正案   |
| ---------- | ------ | ------ | ------ | ------ | -------- |
| <観点名> 2 | high   | <箇所> | <問題> | <根拠> | <修正案> |

### 統合時の訂正

- <レビュア報告を訂正・確定した事実と、確定に使った条件 (食い違い / 定義越え / 重複計上) と根拠。採らなかった評価とその理由もここに書く。>

### 修正と再判定

- <観点名> 2: <修正の内容> → 再判定 ○。あわせて <影響した項目> を再判定し ○。

### チェックリスト外の付記

- <項目に無い問題の 1 行>
```

書き方の規則は次のとおり (詳細は checklist skill の「判定」「報告」)。

- 集計の対象外は ○ にも × にも含めない。
- 集計・判定表・成否は、修正して再判定した場合は再判定後の最終状態で書く。
- 指摘は発見した × の記録であり、修正で解消しても消さない。修正済みの指摘に対応する判定表の行は ○ とし、理由に修正済みの旨を書く。
- 判定表は全項目を載せる。○ の理由は省略してよい。× と対象外の理由は必須。
- レビュア報告の未受領等で判定されなかった項目は、判定欄に「未判定」と理由を書く。未判定は ○/×/対象外のいずれにも数えず、`[critical]` の未判定は全体成否の規則 (checklist skill の「判定」) に従う。
- 「統合時の訂正」はレビュア subagent モードで判定を訂正・確定した場合に書く。self-check のみの実行では「無し」と書く。
- 「修正と再判定」は self-check で修正した場合に書く。修正しない実行では「無し」と書く。
- 同種の付記が繰り返し出たら、項目への昇格を呼び出し側 skill への改訂シグナルとして報告の末尾に 1 行添える。

# 記入例

checklist-template.md の記入例 (リリースノート生成 skill) を self-check で実行した報告の例。

```markdown
## 検証結果

- 対象: /home/user/app/docs/releases/v2.3.0.md
- チェックリスト: release-notes skill の「検証」節
- 実行モード: self-check
- 集計: 形式 4 項目中 ○ 4、× 0、対象外 0 / 内容 3 項目中 ○ 2、× 0、対象外 1 — 成功 (`[critical]` 全 ○)

### 判定

| 項目   | 判定   | 理由                                         |
| ------ | ------ | -------------------------------------------- |
| 形式 1 | ○      |                                              |
| 形式 2 | ○      |                                              |
| 形式 3 | ○      | 終了コード 0 (指摘 0 件)                     |
| 形式 4 | ○      | 発見時 × (指摘参照)、修正して再判定 ○        |
| 内容 1 | ○      |                                              |
| 内容 2 | 対象外 | 本リリースに破壊的変更が無く、該当箇所が無い |
| 内容 3 | ○      |                                              |

### 指摘

| 項目   | 重要度 | 箇所 | 問題                       | 根拠                              | 修正案                                  |
| ------ | ------ | ---- | -------------------------- | --------------------------------- | --------------------------------------- |
| 形式 4 | low    | L23  | 別リリースの PR へのリンク | PR #812 のマイルストーンは v2.4.0 | 対応する v2.3.0 の PR #798 へ差し替える |

### 統合時の訂正

- 無し (self-check のため)

### 修正と再判定

- 形式 4: L23 のリンクを PR #798 へ差し替え → 再判定 ○。形式 3 (lint) を再実行し終了コード 0 で ○ を維持。

### チェックリスト外の付記

- 無し
```
